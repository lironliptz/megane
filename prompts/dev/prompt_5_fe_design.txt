=== prompt ===
Create and apply a **frontend design spec** for megane using the **`frontend-design`**
skill (`.claude/plugins/.../frontend-design/SKILL.md` or Cursor equivalent).

This prompt owns **visual identity, layout density, and global chrome** — not feature
logic. It applies across all static pages and sets tokens that prompts 1, 3, and 4
(company picker, tabbed company view, timeline chart) inherit.

**Product:** SEC filing research for serious users (analysts, founders, ops). Tone:
**credible and precise, not playful startup marketing** — but also **not generic
AI-template UI** (warm cream + terracotta serif, or cookie-cutter dashboard).


## Goal

1. Define a megane-specific design direction brief for the `frontend-design` skill.
2. Ship a cohesive visual system: logo mark (eyeglasses), header, tokens, compact spacing.
3. Keep the **canvas wide** for tables, filings, and the Timeline chart (prompt 3).
4. Update every page shell consistently (`index`, `companies`, `company`, `login`, `admin`).


## Brand anchor

**megane** (メガネ) = **eyeglasses** in Japanese — the product helps you *see* filings clearly.

| Element | Requirement |
|---------|-------------|
| **Wordmark** | `megane` in header — lowercase, deliberate (not shouting) |
| **Icon** | Minimal **eyeglasses** mark beside the wordmark (SVG, not emoji) |
| **Meaning line** | Optional subtle tagline near logo on marketing pages only: "See filings clearly" — **not** in the dense company/timeline header |
| **Favicon** | Replace current battery icon (`static/favicon.svg`) with glasses mark on brand background |

The glasses icon should read at 16×16 (favicon) and 24×24 (header). Single-color or
two-tone using `--accent`; no photorealistic illustration.


## Aesthetic direction (brief for `frontend-design` skill)

When invoking the skill, pass this pinned brief:

> **Subject:** Financial filing intelligence — SEC documents, timelines, price overlays.
> **Audience:** Professional users who spend hours in data-dense views.
> **Job:** Scan identity → filings → timeline without visual fatigue.
> **Tone:** Serious research tool (Bloomberg terminal meets modern SaaS), not consumer fintech hype.
> **Risk to take:** Eyeglasses as a refined geometric mark + a cool, analytical accent (lens-blue or steel) instead of warm orange startup gradients.
> **Avoid:** Terracotta/cream serif hero templates, oversized marketing heroes, excessive border-radius pills, decorative gradients on every card.

### Palette (starting tokens — refine in skill pass, then codify in CSS)

| Token | Direction | Notes |
|-------|-----------|-------|
| `--bg` | Cool neutral (~`#f4f6f9`) | Not warm cream `#faf9f7` |
| `--surface` | White / near-white | Cards, header |
| `--surface2` | Slight cool gray | Hover, nested rows |
| `--border` | Hairline cool gray | Tables, dividers |
| `--accent` | Analytical blue (~`#2563eb` or lens-blue) | Links, active tab, chart accent |
| `--accent-h` | Darker blue hover | Buttons |
| `--text` | Near-black cool | `#0f172a` range |
| `--text-muted` | Slate gray | Metadata, CIK, dates |
| `--success` / `--warning` / `--danger` | Restrained | FIN badges, errors — no neon |

Chart series (Timeline): price line `--accent`; event markers use tier weights (MAJOR =
accent fill, MINOR = muted border only) — document in prompt 3 LLD, colors from here.


### Typography

| Role | Direction |
|------|-----------|
| **UI / body** | Inter or **IBM Plex Sans** — excellent tabular nums for CIK, dates, prices |
| **Display (optional)** | One restrained face for page titles only — not a loud serif on every hero |
| **Data** | `font-variant-numeric: tabular-nums` on tables, pager, chart axes |

Scale down vs current: base `15px`, tighter line-height (`1.45`) on dense pages.


### Layout principles

**Wide canvas (non-negotiable for timeline):**

```css
--layout-max-width: 1680px;          /* keep or bump to 1760px if needed */
--layout-wide-max-width: 1920px;     /* company + timeline pages only */
--modal-wide-max-width: min(98vw, 1520px);
```

Company page (`/companies/:cik`) and Timeline tab use `--layout-wide-max-width`; picker
and login stay at `--layout-max-width`.

**Compact density (reduce wasted space):**

| Area | Current (approx) | Target |
|------|------------------|--------|
| Header height | 58px | **48px** |
| `.main-content` padding | `2rem` | **`1rem 1.25rem`** (clamp) |
| `.card` padding | generous | **`1rem 1.15rem`** |
| `.hero-card` on data pages | large title block | **Remove or shrink** on `company.html` — company name + tabs only; no marketing hero |
| Table cell padding | default | **`0.45rem 0.6rem`** |
| Tab bar | n/a (prompt 3) | **`40px` row**, underline active tab, no pill tabs |

Cards: prefer **flat + border** over heavy shadow stacks. One shadow level (`--shadow`).

**Do not** shrink the Timeline chart area — chart container `min-height: 420px` (desktop),
full width of the wide layout column.

## `frontend-design` skill workflow

1. **Read** the skill file; run its two-pass process (plan → self-critique → build).
2. **Input** this prompt's "Aesthetic direction" + "Brand anchor" sections verbatim.
3. **Output** before coding:
   - Named hex palette (4–6 colors)
   - Type pairing decision
   - One-sentence **signature element** (expected: geometric glasses mark + analytical blue)
   - ASCII wireframe: header + company page with Timeline tab (wide chart)
4. **Self-critique:** reject if the plan matches generic cream/terracotta template defaults
   unless explicitly justified for *financial clarity*.
5. **Implement** in `static/css/style.css` + assets; no React, no build step.
6. **Screenshot check** (if available): login, companies picker, company timeline at 1440px and 1920px width.
