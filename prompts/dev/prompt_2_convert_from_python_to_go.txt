=== prompt ===
Port the Python EDGAR tooling under `python/edgar/` to Go.

These scripts download SEC filings into `fileDB/`, classify each filing, and
write derived `meta.json` beside each accession folder. The Go port becomes
the canonical ingestion + enrichment layer for megane. **Phase 1 keeps JSON on
disk as the database** (same layout as today). SQLite tables may come later —
design types and interfaces so persistence can be swapped without rewriting
classification or download logic.

Relates to `prompts/dev/prompt_1_display_basic_company_data.txt`: the
`internal/filedb` read layer should consume the JSON shapes defined here.


## Goal

Replace `python/edgar/` with a Go package that:

1. Models SEC submissions, filing manifests, and derived filing metadata
2. Downloads company filings from `data.sec.gov` / `www.sec.gov`
3. Builds `meta.json` for each accession folder (tier, category, summary, tags)
4. Exposes CLI commands equivalent to the Python scripts

Keep **byte-for-byte compatible JSON output** where practical so existing
`fileDB/companies/0001567529/` data and prompt-1 UI keep working.


## Source inventory (Python → Go)

| Python file | Role | Go equivalent |
|-------------|------|---------------|
| `build_meta.py` | Core: read `filing.json` + HTML/XML on disk → `meta.json` | `internal/edgar/meta/builder.go` + tests |
| `build_meta_all.py` | Batch CLI: walk company dir, skip existing unless `--all` | `cmd/edgar-meta/main.go` or `make edgar-meta` |
| `fetch_kamada.py` | Fetch `submissions.json`, download last N years of filings | `cmd/edgar-fetch/main.go` |
| `backfill_primary_docs.py` | One-off: download missing `primaryDocument` files | `cmd/edgar-backfill/main.go` |

**Port order:** `build_meta` (+ tests) → `build_meta_all` → `fetch` → `backfill`.

The classification logic in `build_meta.py` is the highest-value piece — port
it faithfully before touching network code.


## Feasibility

**Yes — straightforward Go port.** No exotic Python dependencies:

- `json` → `encoding/json`
- `pathlib` / `os` → `path/filepath`, `os`
- `re` → `regexp`
- `html.unescape` → `html.UnescapeString`
- `xml.etree` → `encoding/xml` (ownership forms) or targeted regex where Python uses regex anyway
- `requests` → `net/http` with shared client, context, timeouts

Main care points:

- SEC **User-Agent header is mandatory** — read from env (e.g. `SEC_USER_AGENT`)
- Rate limit **≥120 ms between requests** (Python uses 0.12 s)
- HTML/XML parsing: filing agents vary; preserve Python's tolerant `errors="ignore"` reads
- `filings.recent` in submissions.json uses **parallel arrays** — model explicitly

## CLI behavior

### `edgar-meta [company_dir] [--all]`

- Default dir: `fileDB/companies/0001567529`
- Find dirs containing `filing.json` (recursive)
- Skip if `meta.json` exists unless `--all`
- Print: `{filingDate} {form} tier={tier} {accession}`
- Exit 1 if any folder errors

### `edgar-fetch --cik=0001567529 [--years=10]`

- Download `submissions.json` → `{fileDB}/companies/{cik}/`
- Filter filings to last N calendar years
- For each accession: write `filing.json`, fetch `index.json`, download missing files
- Call `meta.Build` after each filing folder is populated
- Idempotent: skip files that already exist on disk

### `edgar-backfill --cik=0001567529`

- Port `find_real_gaps()` logic: skip XSL-viewer paths (`/` in name, `.xml` suffix)
- Download missing `primaryDocument` only
