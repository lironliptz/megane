=== prompt ===
Fetch and cache **daily stock price history + volume** for companies already in the system
(CIK + tickers from `submissions.json` / `internal/filedb`).

This prompt owns the **market-data provider**, **SQLite storage**, and the **wire contract**
for price bars fed to the Timeline tab. It does **not** own Chart.js rendering — but it
**must** supply **adjusted close and volume** for every trading day so prompt 3 can plot
price and volume side by side.

**Canonical detail:** `prompts/dev/prompt_4_stock_data-hld.md` (provider audit, chunking,
schema) and `prompt_4_stock_data-lld.md` (file-by-file). **This file supersedes its own
earlier Stooq + 10-year-cap draft** — implement from the HLD when they disagree.

Builds on prompt 1 (`filedb` — `identity.tickers[0]`) and feeds prompt 3 (Timeline API).
No LLM involved.


---

## Goal

1. **`internal/marketdata`** — fetch daily OHLCV from Yahoo (primary) with Tiingo fallback;
   polite **chunked** backfill of **full available history** (not capped at 10 years).
2. **`internal/db/stock_prices`** — store **adjusted close** and **volume** per
   `(cik, trade_date)`; idempotent upsert; incremental refresh.
3. **Timeline contract** — `GET /api/companies/:cik/timeline` returns `prices[]` where each
   point includes **`close`/`adjClose` and `volume`** so the UI can show trading activity
   alongside the price line.


---

## Product requirement — volume alongside price

> Alongside the stock value, we need **volume** as well.

Interpretation for this prompt (data layer):

| Layer | Requirement |
|-------|-------------|
| **Provider fetch** | Every `DailyBar` must include `Volume int64` when the source provides it (Yahoo `quote.volume`, Tiingo `volume`). Do not drop volume to simplify the schema. |
| **SQLite** | `stock_prices.volume INTEGER NOT NULL DEFAULT 0` — store zero when the provider sends null/missing for a bar, but log once per fetch if volume is systematically absent. |
| **Timeline API** | `PricePoint` includes `"volume": 102400` on each row (already sketched in prompt 3). **Not optional for chart use** — omit from JSON only when the entire series has no volume data (provider failure), not per-row laziness. |
| **UI (prompt 3 / 7)** | Render volume in the chart real estate — e.g. **volume bars** in a lower band of the same chart area, or a second y-axis series. **Out of scope here**, but blocked if this prompt fails to persist volume. |

**Acceptance:** For Kamada `KMDA`, a spot-check of cached rows shows non-zero volume on
typical trading days; timeline JSON includes volume on the same dates as `close`.

| Provider | Role | Notes |
|----------|------|-------|
| **Yahoo Finance chart API** | **Primary** | Free, no key; **`adjclose`** + **`quote.volume`**; requires `User-Agent`; 429 → backoff |

**History depth:** fetch **all available daily history** in **5-year chunks** (env-configurable),
not a single `range=10y` call and not a hard 10-year ceiling. Store everything returned;
Timeline **All** preset spans cached coverage.

chunks and `meta.firstTradeDate` stop condition per LLD).

## Storage — `internal/db` (not a new package)

Append to `versionedMigrations` in `internal/db/db.go` ( **`migrations.sql` is stale** ):

```go
{32, `CREATE TABLE IF NOT EXISTS stock_prices (
    cik          TEXT     NOT NULL,
    trade_date   TEXT     NOT NULL,   -- YYYY-MM-DD
    open         REAL,
    high         REAL,
    low          REAL,
    close        REAL     NOT NULL,   -- adjusted close (canonical chart price)
    raw_close    REAL,                -- unadjusted when source provides it
    volume       INTEGER NOT NULL DEFAULT 0,
    currency     TEXT     NOT NULL DEFAULT 'USD',
    source       TEXT     NOT NULL,   -- yahoo | tiingo
    fetched_at   DATETIME NOT NULL,
    PRIMARY KEY (cik, trade_date)
)`},
```

Methods in `internal/db/stock_prices.go`:

```go
func (d *DB) UpsertStockPrices(cik string, rows []StockPrice) error
func (d *DB) StockPrices(cik, from, to string) ([]StockPrice, error)
func (d *DB) StockPriceCoverage(cik string) (earliest, latest string, count int, err error)
```

`StockPrice` struct: `TradeDate`, OHLC, `Close`, `RawClose *float64`, **`Volume int64`**, `Currency`, `Source`, `FetchedAt`.

## Provider package — `internal/marketdata`

Flat package (mirrors `internal/llm`):

```
internal/marketdata/
  provider.go   # DailyBar, Provider interface, HTTP client + UA
  yahoo.go      # period1/period2 chunks, adjclose + volume parse
  tiingo.go     # keyed fallback, same shape
  backfill.go   # EnsureCoverage, RefreshIfStale, chunk walker
```

```go
type DailyBar struct {
    Date     string
    Open, High, Low, Close float64
    RawClose *float64
    Volume   int64   // required field — map from provider; 0 if truly absent
    Source   string  // yahoo | tiingo
}

type Provider interface {
    DailyRange(ctx context.Context, ticker, from, to string) ([]DailyBar, error)
}
```

**Adjusted close:** Yahoo `indicators.adjclose` → stored `close`; raw `quote.close` → `raw_close`.
**Volume:** Yahoo `indicators.quote[0].volume[i]` aligned with `timestamp[i]`; Tiingo `volume` /
`adjVolume` per LLD.

Ticker resolution: caller passes `identity.tickers[0]` — this package does not know CIK.

## Backfill / refresh

1. **First Timeline visit** (empty `stock_prices` for CIK): chunked full history backward until
   `firstTradeDate` (Yahoo) or provider error; upsert after each chunk (crash-safe).
2. **Later visits:** if `latest` within one trading day of today → DB only. Else delta-fetch
   `[latest+1, today]` and upsert.
3. **No cron** in this prompt — lazy refresh on read (prompt 3 handler calls
   `RefreshIfStale` / `EnsureCoverage`).

Env (`.env.example`):

```
MARKET_DATA_PROVIDER=yahoo          # yahoo | tiingo
MARKET_DATA_API_KEY=                # Tiingo fallback only
MARKET_DATA_USER_AGENT=megane/1.0   # mandatory for Yahoo
MARKET_DATA_CHUNK_YEARS=5
MARKET_DATA_CHUNK_DELAY=400ms
```

## Timeline API contract (prompt 3 consumer)

After refresh, handler reads `StockPrices(cik, window.from, window.to)` and maps to:

```json
"prices": [
  { "date": "2024-01-02", "close": 4.12, "adjClose": 4.37, "volume": 102400 }
],
"priceCoverage": {
  "earliest": "2013-05-31",
  "latest": "2026-08-25",
  "source": "yahoo"
}
```

Rules:

- **`volume`** populated from DB for every bar in range when provider supplied it.
- **`priceCoverage`** reflects **cached DB** span, not the requested window.
- Provider failures → `priceCoverage: null` + note; events still returned (prompt 3 D7).

Prompt 3 UI should use **`adjClose ?? close`** for the price line and **`volume`** for a
companion series (bars or secondary axis) in the enlarged chart area (prompt 5 / recent CSS).
